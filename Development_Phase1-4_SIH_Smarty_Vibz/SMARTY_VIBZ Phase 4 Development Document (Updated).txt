1. Phase 4 Objective
Phase 4 is the final product layer.
The previous phases provide the backend intelligence:
- Phase 1: Schedule ingestion, multi-format progress extraction (free text, Excel, Time Agent), SQLite storage
- Phase 2: Hybrid schedule matching with benchmark accuracy evaluation
- Phase 3: Confidence engine, planner review (approve/correct/reject/create new), audit trail

Phase 4 makes all of this accessible through a professional web application.
The Phase 4 goal is:
"Can we demonstrate the complete Smarty_vibz product from a single user interface — including the Time Agent, institutional memory insights, and edge case handling?"

11. Time Agent Page (NEW)
Create a dedicated Time Agent chat interface.
This is a critical addition that directly addresses the problem statement's requirement for "an LLM-based conversational interface ('time agent') for site supervisors."

UI Design:
- Chat-style interface (messages on left, supervisor input on right or bottom)
- Supervisor types natural language progress reports
- Agent responds with:
  - What it understood (extracted structured data)
  - Confirmation that the event was logged
  - If matching is available: the top match with confidence score
  - Conversational follow-up prompt

Example conversation:

[Supervisor]: Started XX-101 spool erection at 9:30 AM in Area B

[Time Agent]: Got it. I've logged:
  Piping — START — XX-101 spool erection
  Date: 2026-08-30 | Time: 09:30 | Location: Area B

  Matched to: PIP-1023 (Erect Line 24"-XX-101)
  Confidence: 94% — Auto-confirmed

  Anything else?

[Supervisor]: match it

[Time Agent]: Already matched! PIP-1023 — 94% confidence.
  You can log another report or ask "what did I log today?"

[Supervisor]: show me what I logged today

[Time Agent]: Here's what you've logged today:
  1. 09:30 AM — PIP-1023 — XX-101 spool erection — AUTO MATCHED
  2. 11:15 AM — Review required — Work started around XX-101

Features:
- Multi-turn conversation support
- If a field is missing from the supervisor's input, the agent asks for clarification:
  "What discipline was this for?" or "Which area was this in?"
- Never hallucinate missing data — if unsure, ask
- Loading state while extracting and matching
- Error state if backend is unavailable
- Session indicator showing logged events count

18. Planner Actions
Approve — call POST /reviews/{review_id}/approve, update status, refresh.
Correct — display candidates, allow selection, call POST /reviews/{review_id}/correct.
Reject — show confirmation, allow optional note, call POST /reviews/{review_id}/reject.
Create New Activity (NEW) — when no candidates match:
- Show "Create New Activity" form
- Fields: activity_code, activity_name, discipline, wbs (optional), planned_start (optional), planned_finish (optional), reviewer_note
- Call POST /reviews/{review_id}/create-new
- After success: show new activity in schedule, update dashboard, create audit record
- Display the new activity with "Unplanned" badge

20. Institutional Memory / Insights Page (NEW)
This page is a critical differentiator for the SIH demonstration.
It directly addresses the problem statement's requirement for "a foundation for institutional memory building — a growing, queryable repository of real project execution patterns."

The Insights page queries the final matched and audited dataset and displays:

20.1 Schedule Variance Insights
- Activities that are behind plan (actual start > planned start)
- Activities that are ahead of plan
- Average delay by discipline

20.2 Activity Performance
- Actual duration vs. planned duration for completed activities
- Activities that took longer than planned
- Activities that finished early

20.3 Discipline Performance
- Match rate by discipline (how often discipline-specific reports are correctly matched)
- Pending reviews by discipline
- Auto-match rate by discipline

20.4 Matching System Performance
- Top-1 accuracy (from Phase 2 benchmark)
- Top-3 accuracy
- Precision at high confidence
- Unmatched rate
- Average processing time
- Auto-match count vs. planner review count

20.5 New/Unplanned Activities
- Count of activities created by planners that were not in the original schedule
- These represent work that was done but not planned — a valuable insight for future planning

20.6 Historical Patterns
- Recurring delay causes (if review notes are available)
- Productivity by discipline, contractor, or activity type
- Most common matching patterns
